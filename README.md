# UBook

Static marketing site for UBook: stablecoin setup and monthly reconciliation for overseas Chinese freelancers and small teams in Hong Kong, Taiwan, Singapore, Malaysia, Japan, North America, and Europe. Funds stay in the client’s own wallet.

Publish the repository root as-is on Vercel, Netlify, or Cloudflare Pages. There is no build step.

The header and footer wordmark is the text “UBook” in Inter. Chinese text uses a self-hosted Noto Sans SC subset. Both fonts are under the SIL Open Font License in `assets/fonts`.

## Call-to-action links

Edit only `assets/cta.js`:

- `BOOK_DIAGNOSIS` — 预约免费收款体检
- `FREE_TEMPLATE` — 免费领取稳定币收款模板
- `CF_BEACON_TOKEN` — Cloudflare Web Analytics. Leave it empty and the beacon does not load.
